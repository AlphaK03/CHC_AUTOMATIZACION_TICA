# Identidad CHC

Recursos proporcionados por el usuario desde `SYS_CARGA_TRANSITO/Logos_CHC`.
Se copian al Workbench para que la aplicación no dependa de esa carpeta externa.

- `chc-symbol.svg`: copia de `Vectorizados/CHC_simbolo.svg`, incluido en
  `CHC_vectorizados.zip`. `BrandMark.qml` lo muestra sobre una base blanca para
  conservar los colores originales en ambos temas, en la barra lateral y Acerca de.
- `chc.ico`: copia de `Logo_CHC_REPORTES.ico`, con tamaños 16, 32, 48, 64, 128 y
  256 px para la ventana y la barra de tareas de Windows.

Los archivos originales permanecen intactos. La identidad de Windows usada por
el proceso del panel es `CHC.Consultores.Workbench`; no se cambia la identidad
del control de instancia única ni de los procesos de los bots.
